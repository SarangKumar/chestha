# Your own background image

Drop an image in this folder and pick it in **Settings → Appearance → Background**.
Files here are served from the app itself — nothing is fetched from the internet.

Use an image you have the right to use. A picture found on Pinterest, Unsplash's
"download" button, a wallpaper site or a search result is usually someone else's
work: fine to set as your own wallpaper, not fine to redistribute inside an app
you publish. If you ever share this build, check each file here first.

Supported: whatever the browser renders — JPG, PNG, WebP, AVIF, SVG.

Keep it reasonably sized. The file loads on every page view and is copied into
every extension build, so a 10 MB photo costs you 10 MB on each one. Around
300–600 KB at your screen's resolution is plenty.

The **Dim** slider in Settings darkens the image behind the interface. Text
contrast was verified against the app's own surfaces, not against an arbitrary
photo, so some dimming is usually needed for the interface to stay readable.
